Conversational AI for the Ness website

About the Widget

The Ness Chatbot Widget is a React-based chat interface that can be embedded in any website. It provides an intuitive way for visitors to interact with the Ness AI assistant.

Ready for Phase 11 Integration

Features

💬 Real-time Chat

Send messages and get instant responses from the AI

⚡ Quick Actions

Suggest common tasks for faster navigation

🎨 Customizable UI

Easily adjust colors and styling to match your brand

📱 Responsive Design

Works seamlessly on desktop and mobile devices

🔧 Minimal Dependencies

Only requires React and ReactDOM

🚀 Standalone Mode

Can run in any webpage via script tag

Integration Guide

Add the widget to your website in just one step:

<script src="https://api.ness.com/widget/dist/widget.js"></script> <script> NessChatbotWidget({ apiUrl: 'https://api.ness.com', siteId: 'ness' }); </script>

🔌 API Configuration

API URL: Points to the backend FastAPI server

Site ID: Identifies which site configuration to load

Session Management: Initialized via POST /session/start

Message Handling: Powered by POST /message endpoint

Architecture

The widget follows a modular React architecture:

ChatWidget Component ├─ Session Initialization (Load config & welcome) ├─ Message Display (User & Bot messages) ├─ Quick Actions (Suggested replies) ├─ Input Area (Message input + send) └─ Embedded Styling (Self-contained CSS)
